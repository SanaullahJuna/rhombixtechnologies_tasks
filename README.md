# Basic Network Sniffer

## Description
A Python-based network sniffer that captures IPv4 packets and displays packet information.

## Features
- Capture network packets
- Extract source and destination IP
- Detect TCP, UDP, ICMP protocols
- Display TTL and packet size

## Technologies Used
- Python
- Socket Programming
- IPv4 Protocol

## How to Run

1. Run VS Code as Administrator
2. Install Python
3. Execute:

python network_sniffer.py

## Output

Displays:
- Source IP
- Destination IP
- Protocol
- Packet Length
- TTL
